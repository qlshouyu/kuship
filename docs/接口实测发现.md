# rainbond-console 接口实测发现（对接校准）

> 实测环境：http://localhost:7070 · 账户 admin · 登录头 `Authorization: GRJWT <token>`
> 沙箱团队：`tenant_name=ogna6xjl`（kuship接口测试，未绑定集群）

## 一、通用规律

1. **登录**：`POST /console/users/login`，form 表单 `nick_name=admin&password=12345678` →
   返回 `data.bean.token`（JWT）。后续所有请求头：`Authorization: GRJWT <token>`。
2. **统一响应信封**：`{code, msg, msg_show, data:{bean, list, ...}}`，`code=200` 为成功；
   分页接口在 `data` 下附加 `total_count / page / page_size`。
3. **region 作用域写接口**（`RegionTenantHeaderView`）**必须带 `?region_name=<region>`**，
   否则返回 `400 请求参数不全`。涉及：角色改/删、团队改名、证书、注册凭证等大量 team/app 写接口。

## 二、入参/方法校正（文档已对齐）

| 接口 | 校正点 |
|---|---|
| `POST /console/teams/{team}/modifyname` | 实为 **POST**，UI 侧若用 PUT 会 405 |
| `POST /console/users/access-token` | `age` 必须为**数字**（传字符串 500） |
| `PUT /console/enterprise/{eid}/app-model/{app_id}` | 必须传 `tag_ids`（数组），否则 500 |
| `POST /console/teams/{team}/certificates` | 必须传 `certificate_type`（如 `ssl`），否则 DB 非空约束 500 |
| `POST /console/hub/registry` | 会做仓库连接测试，需**真实可达仓库** |

## 三、后端缺陷（该 rainbond 版本真实 bug，对接需规避）

| 接口 | 错误 | 位置 |
|---|---|---|
| `POST /console/teams/{team}/registry/auth` | `create_registry_auth() missing 2 args: hub_type, user_id` | team.py:1187 |
| `DELETE /console/enterprise/{eid}/user/favorite/{id}` | `name 'favorite' is not defined` | user_operation.py:563 |
| `DELETE /console/users/access-token/{user_id}` | `name 'access_key' is not defined` | user_accesstoken.py:74 |
| `PUT /console/enterprise/{eid}/app-model/{app_id}` | `'NoneType' object is not iterable`（缺 tag_ids） | center_pool/apps.py:310 |
| `POST /console/hub/registry`（错误分支） | `local variable 'response' referenced before assignment` | registry.py |
| `POST /console/teams/{team}/plugins`（未绑集群时） | `'Http404' object has no attribute 'message'`（错误处理 bug，掩盖了"团队未在集群注册"的真实原因） | plugin_create.py:180 |

> 说明：`DELETE` 的 NameError **不是普遍问题**——roles / app-model / hub-registry / certificates 的 DELETE 均正常 200，仅 favorite / access-token 两处删除处理器有此缺陷。

## 四、已实测 200 的写接口（含真实出参）

| 接口 | 方法 | 出参要点 |
|---|---|---|
| `/console/teams/add-teams` | POST | Tenants 全字段（ID/tenant_id/tenant_name/namespace/tenant_alias…） |
| `/console/teams/{team}/roles` | POST | `{ID, name, kind_id, kind}` |
| `/console/teams/{team}/roles/{role_id}` | PUT / DELETE | PUT 返回 `{ID,name}`；DELETE 空 bean（需 region_name） |
| `/console/teams/{team}/modifyname` | POST | Tenants 全字段（需 region_name） |
| `/console/enterprise/{eid}/user/favorite` | POST/PUT | `{name,url,favorite_id,custom_sort,is_default}` |
| `/console/enterprise/{eid}/app-models/tag/{id}` | POST/PUT | 标签 `{name,tag_id}` |
| `/console/enterprise/{eid}/app-models` | POST | 创建 RainbondCenterApp（删除可逆） |
| `/console/enterprise/{eid}/app-model/{app_id}` | DELETE | 删除应用模型 |
| `/console/users/access-token` | POST | `{ID,note,user_id,access_key,expire_time}`（age 为数字） |
| `/console/teams/{team}/certificates` | POST/DELETE | 上传 `{alias,certificate_type,certificate,private_key}` → `{alias,id}` |
| `/console/hub/registry` | DELETE | 删除镜像仓库（幂等 200） |
| `/console/errlog` | POST | 前端错误上报 |

## 五、范围说明

- 写接口共 ~430（POST 235 / PUT 109 / DELETE 87）。
- **自包含、不依赖应用、不改全局配置**的 DB 安全写接口已基本实测覆盖（约 24 个）。
- 其余绝大多数写接口在 **service 层调用 `region_api.*` 操作集群**（创建/构建/部署/伸缩/删除组件、绑定数据中心等），
  需要"集群已绑定 + 真实应用/组件"上下文，按约定（仅测 DB 安全类）**未实测**，保留后端静态解析的字段+示例。
- 沙箱残留（待清理）：测试团队 `ogna6xjl`、access-token(ID 76)、favorite(id 1)、tag(id 26)；
  其中 favorite/access-token 因后端 DELETE bug 无法经 API 删除。
